# .github

makecindy 组织的公共配置仓库。

- `profile/README.md`：组织首页（<https://github.com/makecindy>）展示的 profile。
- `profile/assets/`：profile 引用的品牌资源。
  - `cindy-wordmark-light.svg` / `cindy-wordmark-dark.svg`：wordmark 明暗两版，自矢量源派生导出；矢量源在内部品牌资产库维护，修改请先改源头再同步导出。

Logo、wordmark 等品牌资产仅供 Cindy 官方使用，不随本仓库以开源许可证授权。
